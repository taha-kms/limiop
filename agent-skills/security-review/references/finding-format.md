# Security Finding Format

Use a compact format for actionable findings.

## Severity - Title

**Location:** file/component

**Risk:** Describe the concrete vulnerable behavior and attacker prerequisites.

**Impact:** Describe realistic impact.

**Fix:** Give the smallest robust remediation.

**Verification:** State the regression/security test or manual check needed.

Use severity based on exploitability and impact in SkillSync's actual deployment context.

If something is only hardening, label it as hardening rather than a confirmed vulnerability.
